# Seolwoni Pack Library

Minecraft inventory & hotbar resource pack archive by Seolwoni.

Live site: https://seolwoni.github.io

## Adding a pack
1. Put preview images in `assets/` (`<id>_inv.webp`, `<id>_hud.webp`).
2. Copy one block in the `PACKS` list near the bottom of `index.html` and fill it in.
