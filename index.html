Seolwoni Pack Library

Animated inventory & hotbar resource packs for Minecraft Java. All free.

How to install

  1. Install the required mod: Animatica Refabricated (Fabric or NeoForge). The inventory only animates with this mod.
  2. Click Download to get the .zip file. Don't unzip it.
  3. In Minecraft, go to Options → Resource Packs → Open Pack Folder.
  4. Drop the zip into the folder, move the pack to the right-hand list, then click Done.

Using the CurseForge app? Create a Fabric profile (1.21.8+), add Animatica Refabricated from the mod browser, then open the profile's ⋯ menu → Open Folder and drop the zip into resourcepacks. The packs aren't listed on CurseForge, so add them by hand.

Credits & removal requests

Some pack backgrounds use artwork by other artists. Credits are listed in each pack's details.

If you are the original artist and want something removed, DM me on Instagram and it will be taken down right away.
